# 序：从银幕到十字架

这本书里的二十一篇文章，起初都是为一个小小的网站写的。网站叫“光影与信仰”，原本只是一份路标式的索引：记录华人基督徒作者评过哪些电影，从什么角度切入，原文在哪里。做着做着，我们发现有些电影一直没有人从信仰的眼光认真谈过，或者谈过的文章已经难以找到。于是开始自己写。

写法上，我们给自己立了四条规矩，每一篇都照着做。第一，引用圣经，但经文必须是论证的转轴，而不是文末贴上去的标签；一处贴切的引用，胜过五处装饰性的堆砌。第二，诚实地呈现影片揭示的人心困境，然后走到福音——不停在“我们要学会爱”这样的道德劝勉上，而要走到十字架。第三，从细节里说话：一句台词，一个道具，一个前后呼应的镜头。属灵的解读必须从电影里长出来，而不是套在电影外面。第四，给每个角色留一段肖像。群像片里的每个人往往代表一种人心的样式，把这张“人心地图”画完整，是我们最在意的事。

书中的电影跨度很大：从一九五七年的《第七封印》和《12怒汉》，到近年的《心灵奇旅》与《血战钢锯岭》；有好莱坞的商业大片，也有伯格曼、李沧东的作者电影；有皮克斯的动画，也有张艺谋、文牧野的华语片。我们按主题把它们分成五辑：苦难中的追问，自由与救赎，牺牲与公义，记忆、身份与归家，青春与教育。辑与辑之间并没有硬性的界线，读者大可以从任何一篇读起。

我们并不假定读者是基督徒。如果你只是爱电影，希望这些文章能让你看见一些从前没有留意的细节；如果你正在信仰的门口徘徊，希望这些电影能替我们说出一些不容易直接说出的话。至于书中反复出现的那个名字——耶稣——我们相信，他不是我们从外面加给这些电影的，而是这些故事里早已在场、只是常常被错过的那一位。就像《密阳》的片名所说的：阳光是真的，只是隐秘。

圣经引文均出自和合本。所评影片的版权归各出品方与发行方所有，本书仅作评论。文章的网络版可在“光影与信仰”网站免费阅读，欢迎转发。
