# Skill: 自撰基督信仰影评

> 本站（光影与信仰）从"导读索引"延伸出的原创写作能力：以基督信仰的眼光评论一部电影，写成一篇可独立发表的中文影评。

## 输入

- **电影名**（必需）。
- **风格**（可选）：见 `references/styles.md` 的四种预设，或用户自定义描述。未指定时默认**文学随笔式**。
- **篇幅**（可选）：默认 1800–2800 字。用户可要求短评（600–1000 字）或长文（3500 字以上）。

## 四个基本要求（每篇必须全部满足）

这四条是本站影评的身份标识，任何风格下都不可省略：

1. **引用圣经经文。** 全篇至少引用 2–4 处经文，用和合本译文，标注书卷章节（如"传道书 1:2"）。经文必须与上下文论点真正咬合——是论证的枢纽，不是文末贴的标签。一处贴切的引用胜过五处装饰性的堆砌。

2. **指向耶稣、指向神、指向救赎，指出人心的罪。** 影评的整体走向是一条从影片到福音的路：先诚实地呈现影片揭示的人性困境（罪不只是"坏行为"，更是人心的弯曲——自爱、自义、惧怕、偶像化的爱情或成功），再指出这困境在人自身之内无解，最终指向基督里的赦免与救赎。不要停在道德劝勉（"我们要学会爱"），要走到十字架。

3. **挖掘影片中的叙事和细节。** 评论的说服力来自具体：一句台词、一个道具、一个镜头、一处前后呼应的结构。全篇至少深挖 3–5 个具体细节，让读者感到"作者真的看懂了这部电影"。属灵解读必须从细节里长出来，而不是套在电影外面。

4. **对每个角色都有描述。** 主要角色逐一有肖像式的描写与属灵判语（各 1 段或数句），次要角色至少点到其在主题中的位置。群像片中每个角色往往代表一种人心的样式——把这张"人心地图"画完整，是本站影评区别于普通影评的地方。

## 工作流程

### 1. 核实资料（先于一切写作）

- 查 `data.js` 中是否已有该片条目：拿到 `id`、导演、年份、已收录的他人评论视角（避免雷同，也可对话）。
- 对剧情、角色名、台词**逐一核实**，不确定的用 WebSearch 查证。**宁可省略，不可虚构**——一个编造的"细节"会摧毁整篇影评的可信度。
- 列出角色清单（主角 + 有名有姓的配角），确保写作时无遗漏。

### 2. 找到"福音枢纽"

动笔前先回答一个问题：**这部电影里，人心的病症是什么？福音对它说什么？** 用一句话写下来（如《致青春》：人人都爱自己胜过爱爱情——而福音说，唯有先被那位舍己的爱所爱，人才能走出自爱）。这句话是全文的脊柱，所有细节分析和角色描写都向它汇聚。

### 3. 选定风格并写作

读 `references/styles.md` 中对应风格的写法要点，按其语气、节奏、引经方式行文。通用结构（可按风格微调，不必打小标题）：

0. **标题**：首选影片自己说出的那句"诊断"——最有名的台词或最扎心的一句（可原样引用，也可一字之差地反用，如"青春是用来**记**念的"）。好标题让看过电影的人一眼被击中，没看过的人也起悬念。忌两类：`《XX》影评`式的流水标题，和只有读完全文才懂的隐晦典故（哪怕它在文中很精彩——那是文眼，不是标题）。
1. **开头**：从一个具体场景、台词或细节切入，不要从"这是一部……的电影"开始。
2. **叙事分析**：顺着影片的结构讲它"怎么讲故事"，边讲边埋下属灵观察。
3. **人物群像**：逐个角色的肖像与判语（要求 4）。
4. **转向**：从人物共同的困境收拢到"人心的罪"的诊断（要求 2 前半）。
5. **福音**：经文与基督进场，指出救赎之路（要求 1、2 后半）。结尾落在盼望，而非感伤或说教。

### 4. 自检清单

写完后逐条核对：

- [ ] 2–4 处经文，和合本，有书卷章节，且都在论证中承重？
- [ ] 有明确的"罪的诊断"，且最终指向了基督与救赎（不是停在道德劝勉）？
- [ ] 至少 3–5 个具体细节（台词/道具/镜头/结构），无一处虚构？
- [ ] 每个主要角色都有描述，次要角色点到？
- [ ] 风格与所选预设一致，无陈词滥调（见下方"质量红线"）？
- [ ] 标题出自影片自己的"诊断句"（名台词原用或反用），看过电影的人一眼被击中？不是流水标题，也不是读完才懂的隐晦典故？

## 输出格式

保存为 `original-reviews/<film-id>.md`（`film-id` 用 `data.js` 中的 id；若该片未收录，按拼音短横线规则新造，如 `zhongguo-hehuoren`）。文件头部用 YAML front matter：

```markdown
---
film: 致我们终将逝去的青春
filmEn: So Young
filmId: zhiqingchun
year: 2013
director: 赵薇
style: 文学随笔式
date: 2026-08-13
---

# （影评标题）

（正文……）
```

## 质量红线

这些是常见的失败模式，出现任何一条就该重写相应段落：

- **贴标签式引经**：段落写完了才补一句经文，删掉它论证毫发无损。经文应当是段落的转轴。
- **剧透式复述**：按时间顺序把剧情讲一遍。影评是分析，不是梗概；细节要为论点服务。
- **道德说教腔**："我们应当""让我们都来"式的口号。福音不是要求人变好，是宣告神已成就的事。
- **属灵套话**：不经过影片细节、放在任何电影后面都成立的段落（"这个世界充满罪恶，唯有耶稣是答案"）。诊断必须是**这部**电影的诊断。
- **审判姿态**：把角色钉在耻辱柱上。指出罪时要带着"我们也在其中"的诚实——律法之下没有旁观者（罗马书 3:23）。
- **虚构细节**：记不准的台词不要加引号硬引，改为转述或删去。

## 完成后：发布到站点

站点已支持自撰影评（`review.html` 运行时渲染 Markdown），发布只需两步：

1. **登记注册表**：在根目录 `originals.js` 的 `ORIGINALS` 中新增一条：
   ```js
   "<film-id>": { title: "影评标题（与 md 内一级标题一致）", style: "文学随笔式", date: "YYYY-MM-DD" }
   ```
   登记后：首页该片卡片自动出现"✦ 本站影评"徽标（即使该片没有外部全文摘录也会进入首页索引），电影页自动出现"本站影评"入口，`review.html?id=<film-id>` 即为阅读页。
2. **确认该片在 `data.js` 中有条目**（`film.html`/`review.html` 都依赖它取片名与元信息）。若无，先按 `find-articles.skill.md` 的收录规范新增电影条目（`reviews` 可为空数组）。

注意 `review.html` 的渲染器只支持 Markdown 子集：段落、`##` 二级标题、`>` 引用、`**粗体**`/`*斜体*`。不要在影评正文里使用表格、列表、图片等其他语法。

最后本地预览验证（`python3 -m http.server 8000`），把影评路径与阅读页 URL 告诉用户，附 1–2 句内容简介。
